## 1. How to read a number from the paper back to a file

The paper never quotes a number typed by hand. Every figure is registered in
`protocol/PAPER-NUMBERS.md` (the prose ledger, source of truth) and mirrored into
`protocol/numbers.json` (machine-readable). The mirror is regenerated by
`scripts/desktop/build_numbers.py`, which refuses to run if a declared value does not
appear verbatim in the ledger.

```
paper figure  ->  numbers.json id  ->  ledger section  ->  measurements/<file>.jsonl
```

To verify the link is intact:

```
python scripts/desktop/build_numbers.py --check
```

Exit code 0 means the ledger and the mirror agree. This is the same gate the authors ran
before submission.

## 2. Conventions that change the numbers, stated once

**Percentiles are nearest-rank, no interpolation:** `sorted(v)[round(q*(n-1))]`. This is
the same function (`_pct`, `pxx`) across every script here. It matters: one figure in an
earlier draft differed by 115 ms purely between nearest-rank and linear interpolation.

**Row slices are stated per batch**, never assumed. Several files were appended to after
the original analysis, so a byte-offset slice recorded at the time no longer points where
it did. Where a slice could not be reproduced, the ledger says so and uses a principled
slice (one complete session) instead of one reverse-engineered to match an old number.

**Word error rate is reported under three normalisations**, and they are not
interchangeable: `O-WER` (raw), `N-WER` (lowercase, punctuation stripped, NFC), `D-WER`
(N-WER plus number-word and name-variant folding). By construction `D ≤ N ≤ O`. Any figure
quoted as a single WER in the paper is **D-WER**, the loosest, so it is a *lower bound* on
error. Full definitions and the one place the implementation deliberately departs from the
source paper (Unicode NFC before punctuation stripping, because Vietnamese tone marks are
combining characters and would otherwise be erased) are in `protocol/PROTOCOL.md` §A.

**Proportions carry Wilson 95 % intervals.** Clean counts are never reported as zero
probability: `0/30` is reported with a rule-of-three upper bound of ≤ 10 %, `23/23` with a
Wilson lower bound of 0.857.

**Validity gates are diagnostic labels, not filters.** No analysis here drops a turn for
failing a quality check. Flagged turns are labelled, kept, and both subsets reported —
because an early version of one analysis discarded turns that turned out to sit inside the
accepted cluster.

**Column names shared across the routing files**

| column | meaning |
|---|---|
| `id` | question identifier, stable across every file |
| `lang` | language of the question as asked (`vi` / `en`) |
| `needs_lookup` | the **hand label**: does answering require consulting an external source |
| `lookup` | the **system's decision** on this run — this is what stability is measured on |
| `rep` | repeat index within the batch |
| `position` | where the question sat in the conversation (history lever) |
| `fact_type` | knowledge-dynamics class of the question |
| `reply` | the model's text |
| `annotator`, `labeled_at`, `borderline` | labelling provenance; `borderline` marks items the annotator flagged as arguable |

**Device columns** (`device_floor_*.jsonl`) are documented field by field in
`protocol/DEVICE-FLOOR.md`. The ones that carry the paper's claims:

| column | meaning |
|---|---|
| `t_rx_first` | ms from "start listening" to the first audio frame reaching the server |
| `t_rx_speech_first` | first frame **above the speech threshold** — not the same mark, and mixing them inflates the downlink |
| `t_dev_vad_end` | when the server judged the speaker had stopped |
| `t_tx_first` | when the first reply byte left the server |
| `t_dev_ack` | when the device began playback — **empty in every record ever collected**; this absence is why the downlink had to be measured acoustically |
| `opened_at_perf_ms`, `onsets_perf_ms` | absolute `perf_counter` marks, added 2026-09-10, which let an external recorder be aligned without clock synchronisation |
| `jitter_ms`, `frame_bytes`, `decode_errors`, `rtt_p50` | link quality for the same turn |

### `measurements/baseline/` — frozen

Desktop-only reference, frozen 2026-09-05 and never re-run. Re-running it would destroy
the property that makes it a baseline. Treat as read-only.

### `measurements/langconf/` — multi-turn language-contamination study

A separate factorial study that shares this article's infrastructure. `main_gemini*.jsonl`
is the full grid (61 200 trials); `main_qwen2.5-7b.jsonl` and `main_llama3.1-8b.jsonl` are
the open-weight arms, run locally at 4-bit quantisation. `*_scored.jsonl` files carry the
language-identification verdicts; the raw files carry the prompts.

`rerun_check_qwen2.5-7b.json` is the same-host reproducibility probe: 23 trials replayed
four days later with sampling seed and temperature pinned. It is small and it is the file
behind one of the paper's four claims.

### `scripts/` — everything that produced the above

`scripts/desktop/` holds the benchmark drivers (`bench_*.py`) and the two gates
(`build_numbers.py`, `check_refs.py`). `scripts/langconf/` and `scripts/langconf_lib/` hold
the factorial study. Scripts are included at the revision that produced the data; where a
script was later fixed, the ledger records both the old and new numbers rather than
silently replacing them.

## 4. Known caveats a re-analyst will hit

1. **`lookup_ab_refusal_20260909_v1.jsonl` has no negative half.** It scored only
   lookup-needing questions, so it cannot separate capability from threshold. The paper
   uses it for a single-variable comparison and explicitly not as an operating-point
   analysis.
2. **The `latency_es3c28p_20260910_v1.jsonl` transcripts are not usable for accuracy.**
   That batch ran with a fixed input gain to compensate a ~20 dB loudspeaker-to-microphone
   loss. Timings are unaffected — multiplying amplitude does not move a timestamp — but
   signal level is an intervened variable.
3. **The Vietnamese half of the question set was labelled by one annotator**, with no
   agreement statistic. `borderline` marks the items that annotator flagged.
4. **`grounding_*` compares against the live web.** It is by construction not replayable:
   running it again measures a different web. The 13-hour pair is the measurement.
5. **The device figures are lower bounds.** No oscilloscope was available; the downlink was
   timed acoustically. Host-side noise suppression can swallow an onset but cannot move one
   earlier, so residual error points towards making the device look worse.
6. **One `devout` turn returns 1 466 ms** against a 257–352 ms cluster. It is kept in the
   files and in the tables, flagged, and not explained.

## 5. Reproducing the analysis

```
python scripts/desktop/build_numbers.py --check     # ledger <-> mirror agree
```

The per-batch analyses are the `bench_*.py` scripts; each carries its command line in its
module docstring. Scripts that call a hosted model need credentials that are **not** in this
archive and will not run without them; scripts that only re-analyse the `.jsonl` files need
nothing beyond Python, NumPy and SciPy.
